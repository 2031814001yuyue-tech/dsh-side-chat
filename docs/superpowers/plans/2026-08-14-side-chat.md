# DSH Side Chat 插件 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个可在 GitHub 发布的 DSH 插件 `dsh-side-chat`：并行侧边对话（真实并行 agent 会话、独立上下文、摘要带回主对话），并作为动态 Cordis 插件在本会话内完成定义、运行与验收。

**Architecture:** 单一动态 Cordis 插件、双半体。Host 半体（`src/host.js`）持有内存注册表，通过 `agentLoop.createAgent` 创建真实侧会话（同 preset/工作区、独立上下文），`agent.send` 注入消息，`agent.whenIdle` 等待回合，摘要经 `mainAgent.inject` 注入主会话；提供 `/side` 命令 + 6 个 `harness.handle` RPC。Client 半体（`src/client.js`）在 `sidebar.footer.action` 注册入口按钮、在 `shell.overlay` 注册侧边面板，通过 `host.call` 轮询（1s）渲染。仓库文件即动态插件源码（top-level `return` 函数体格式），README 提供安装说明。

**Tech Stack:** 纯 JavaScript（无 TS/JSX/import/require）；Cordis 动态插件（`ctx.get`/`ctx.on`/`ctx.effect`/`slots.inject`）；DSH 服务 `agents`/`agentLoop`/`sessions`/`sessionQuery`/`commands`/`workspaceRegistry`；React 18（`React.createElement`）。

## Global Constraints

- 纯 JS：无 TypeScript、JSX、`import`/`require`、装饰器；Client 只用 `React.createElement`。
- 仓库文件 `src/host.js` / `src/client.js` 是**动态插件源码**（以 `return { apply(ctx) {…} }` 为顶层语句的函数体格式）；代码改动先改文件，再用 cordis_define 以同内容定义（追加新 Package，绝不覆盖）。
- 只读 live 对象（Session/Agent/Event）的标量叶子字段，禁止 `JSON.stringify`/`structuredClone`/递归枚举 live 对象；RPC 只传 JSON。
- 消息一律手工构造：`{ id: <string>, role: 'user', content: [{ type: 'text', text }], source: { kind: 'user' } }`；注入主会话的摘要用 `source: { kind: 'plugin', plugin: 'sidechat' }`。
- 每主会话最多 **8** 条并发侧对话；超限 `open` 返回错误。
- 摘要注入用 `mainAgent.inject(...)`（不唤醒主 agent）；主 agent `status === 'running'` 时 `bring-back` 拒绝（返回 `'main-busy'`）。
- 关闭侧对话 = `handle.dispose()` + `workspaceRegistry.archiveSession(sessionId)`。
- 插件停止（unload）时 `ctx.effect` 清理全部侧对话 handle。
- 面板轮询 1s（仅面板打开时）；所有样式用主题变量 `--dsw-alias-*`。
- 所有贡献必须挂在插件 Fiber 生命周期内（`ctx.on`/`ctx.effect`/`slots.inject`/`harness.handle`）。
- 验收只能通过本会话实际运行（cordis_define → cordis_run → 浏览器/命令验证）；语法级验证用 `node scripts/check.cjs`（`new Function(code)` 编译，不执行）。

## 已核实的 API 契约（实现时不得偏离）

- Host Builtins：`ctx.get/on/provide/effect`、`harness.handle(method, handler): () => void`、`console`。
- Client Builtins：`ctx`、`React`（`createElement`/`useState`/`useEffect`）、`host.call(method, args): Promise<JsonValue>`、`styles.insert(css): () => void`、`console`。
- `agents.get(id): Agent | undefined`；`agent.send(message, 'next-turn'|'next-step', wakeup: boolean): void`；`agent.inject(message): void`；`agent.whenIdle(): Promise<void>`；`agent.status: 'idle'|'running'`；`agent.options: {provider?, model?, maxTokens?}`；`agent.session.header: {cwd?, agentPreset?, …}`。
- `agentLoop.createAgent(ownerCtx, options): Promise<AgentHandle>`，options：`{ sessionId, meta?: {cwd?, parentSession?, agentPreset?}, agentOptions?: {provider?, model?, maxTokens?}, signal? }`；`AgentHandle { agent, dispose(): Promise<void> }`。
- `sessions.get(id)` / `sessions.flush(session): Promise<boolean>`。
- `sessionQuery.readSession(sessionId): Promise<{session, events: SessionEvent[]}>`；事件 `user/message` 的 `data = UserMessage{content}`，`assistant/message` 的 `data = {turn, step, message: AssistantMessage}`；文本块 `{type:'text', text}`。
- Host Events：`agent/status` `{agent, status}`；`agent/error` `{agent, turn, step, error}`（均为 emit；根上下文监听全部 agent，按 `agent.id` 过滤）。
- `commands.register({name, description, input?: {hint}, recordInput?, handler(invocation)})`；invocation `{agent, rawInput, …}`；handler 返回 `{kind:'success', text?} | {kind:'error', text}`。
- `workspaceRegistry.archiveSession(sessionId): Promise<void>`。
- Client Slots：`sidebar.footer.action`（list，注册 `{name, id, order?, label?}`，ownerProps `{wide}`，standardProps `useSessions`/`useWorkspaces`）；`shell.overlay`（list，注册同上，standardProps `useSessions`/`useWorkspaces`）。
- `props.useSessions((s) => s.current): SessionId | undefined`（`SessionListState.current`）。
- Client `timer` 服务：`ctx.get('timer')` → `interval(callback, delay): () => void`。
- 主题变量：`--dsw-alias-bg-overlay`、`--dsw-alias-bg-layer-1/2`、`--dsw-alias-border-l1/l2`、`--dsw-alias-brand-primary`、`--dsw-alias-label-primary/secondary`、`--dsw-alias-state-error-primary`、`--dsw-alias-state-success-primary`。

- [ ] **Step 1: 写入 `src/host.js`（完整源码，逐字采用）**

```js
/**
 * DSH Side Chat — Host 半体。
 * 每条侧对话 = 一个真实并行 agent 会话（同 preset、同工作区、独立上下文）。
 * 提供 /side 命令与 6 个 Package-private RPC，供 Client 面板调用。
 * 本文件即动态 Cordis 插件源码：以函数体格式加载（顶层 return 插件对象）。
 */
return {
  apply(ctx) {
    const MAX_SIDE = 8
    const SUMMARY_PROMPT = '请用中文把这次侧边对话总结成一段简洁的结论（300 字以内），只输出总结正文，不要任何前缀、标题或客套话。'

    const agents = ctx.get('agents')
    const agentLoop = ctx.get('agentLoop')
    const sessions = ctx.get('sessions')
    const sessionQuery = ctx.get('sessionQuery')
    const commands = ctx.get('commands')
    const workspaceRegistry = ctx.get('workspaceRegistry')
    if (!agents || !agentLoop || !sessions || !sessionQuery || !commands || !workspaceRegistry) {
      console.error('[side-chat] 缺少必需服务（agents/agentLoop/sessions/sessionQuery/commands/workspaceRegistry），插件未启用')
      return
    }

    /** @type {Map<string, {sideId:string, sessionId:string, mainSessionId:string, title:string, status:string, error:string|null, handle:object, updatedAt:number}>} */
    const sideChats = new Map()
    let counter = 0
    let version = 0
    let openSignal = 0

    function bumpVersion() {
      version += 1
    }

    function entryOf(mainSessionId, sideId) {
      const entry = sideChats.get(sideId)
      if (!entry || entry.mainSessionId !== mainSessionId) return undefined
      return entry
    }

    function textOf(content) {
      if (!Array.isArray(content)) return ''
      return content
        .filter((block) => block && block.type === 'text' && typeof block.text === 'string')
        .map((block) => block.text)
        .join('')
    }

    async function lastAssistantText(sessionId) {
      let snap
      try {
        snap = await sessionQuery.readSession(sessionId)
      } catch (err) {
        console.error('[side-chat] readSession 失败', err)
        return undefined
      }
      const events = snap && Array.isArray(snap.events) ? snap.events : []
      for (let i = events.length - 1; i >= 0; i -= 1) {
        const event = events[i]
        if (!event || event.type !== 'assistant/message') continue
        const message = event.data && event.data.message
        const text = textOf(message && message.content).trim()
        if (text) return text
      }
      return undefined
    }

    async function openChat(mainSessionId, firstMessage) {
      const mainAgent = agents.get(mainSessionId)
      if (!mainAgent) return { ok: false, error: '主会话不在线' }
      let count = 0
      for (const entry of sideChats.values()) {
        if (entry.mainSessionId === mainSessionId) count += 1
      }
      if (count >= MAX_SIDE) return { ok: false, error: '侧边对话数量已达上限（' + MAX_SIDE + '）' }
      counter += 1
      const sideId = 'side-' + Date.now() + '-' + counter
      const title = '侧对话 #' + counter
      const handle = await agentLoop.createAgent(ctx, {
        sessionId: sideId,
        meta: {
          cwd: mainAgent.session.header.cwd,
          parentSession: mainSessionId,
          agentPreset: mainAgent.session.header.agentPreset,
        },
        agentOptions: {
          provider: mainAgent.options.provider,
          model: mainAgent.options.model,
          maxTokens: mainAgent.options.maxTokens,
        },
      })
      const entry = {
        sideId,
        sessionId: sideId,
        mainSessionId,
        title,
        status: 'idle',
        error: null,
        handle,
        updatedAt: Date.now(),
      }
      sideChats.set(sideId, entry)
      openSignal += 1
      bumpVersion()
      if (firstMessage) {
        const res = await sendMessage(mainSessionId, sideId, firstMessage)
        if (!res.ok) return { ok: false, error: '已创建但首条消息发送失败：' + res.error }
      }
      return { ok: true, id: sideId, title }
    }

    async function sendMessage(mainSessionId, sideId, text) {
      const entry = entryOf(mainSessionId, sideId)
      if (!entry) return { ok: false, error: '未知侧对话' }
      const trimmed = String(text || '').trim()
      if (!trimmed) return { ok: false, error: '消息不能为空' }
      const sideAgent = agents.get(entry.sessionId)
      if (!sideAgent) return { ok: false, error: '侧对话 agent 不在线' }
      const message = {
        id: 'side-msg-' + Date.now() + '-' + Math.floor(Math.random() * 1e6),
        role: 'user',
        content: [{ type: 'text', text: trimmed }],
        source: { kind: 'user' },
      }
      sideAgent.send(message, 'next-turn', true)
      entry.updatedAt = Date.now()
      return { ok: true }
    }

    function stateOf(mainSessionId) {
      const chats = []
      for (const entry of sideChats.values()) {
        if (entry.mainSessionId !== mainSessionId) continue
        chats.push({
          id: entry.sideId,
          title: entry.title,
          status: entry.status,
          error: entry.error,
          updatedAt: entry.updatedAt,
        })
      }
      chats.sort((a, b) => a.updatedAt - b.updatedAt)
      return { chats, version, openSignal }
    }

    async function eventsOf(mainSessionId, sideId) {
      const entry = entryOf(mainSessionId, sideId)
      if (!entry) return { ok: false, error: '未知侧对话' }
      let snap
      try {
        snap = await sessionQuery.readSession(entry.sessionId)
      } catch (err) {
        return { ok: false, error: '读取会话失败' }
      }
      const messages = []
      for (const event of (snap && Array.isArray(snap.events) ? snap.events : [])) {
        if (!event) continue
        if (event.type === 'user/message') {
          const text = textOf(event.data && event.data.content).trim()
          if (text) messages.push({ role: 'user', text, time: event.time })
        } else if (event.type === 'assistant/message') {
          const message = event.data && event.data.message
          const text = textOf(message && message.content).trim()
          if (text) messages.push({ role: 'assistant', text, time: event.time })
        }
      }
      if (messages.length) entry.updatedAt = messages[messages.length - 1].time
      return { ok: true, messages }
    }

    async function bringBack(mainSessionId, sideId) {
      const entry = entryOf(mainSessionId, sideId)
      if (!entry) return { ok: false, error: '未知侧对话' }
      const mainAgent = agents.get(mainSessionId)
      if (!mainAgent) return { ok: false, error: '主会话不在线' }
      if (mainAgent.status === 'running') return { ok: false, error: 'main-busy' }
      const sideAgent = agents.get(entry.sessionId)
      if (!sideAgent) return { ok: false, error: '侧对话 agent 不在线' }
      const request = {
        id: 'side-sum-' + Date.now(),
        role: 'user',
        content: [{ type: 'text', text: SUMMARY_PROMPT }],
        source: { kind: 'user' },
      }
      sideAgent.send(request, 'next-turn', true)
      entry.status = 'running'
      try {
        await sideAgent.whenIdle()
      } catch (err) {
        console.error('[side-chat] whenIdle 失败', err)
      }
      const sideSession = sessions.get(entry.sessionId)
      if (sideSession) {
        try {
          await sessions.flush(sideSession)
        } catch (err) {
          console.error('[side-chat] flush 失败', err)
        }
      }
      entry.status = 'idle'
      const summary = await lastAssistantText(entry.sessionId)
      if (!summary) return { ok: false, error: '未能生成总结' }
      const message = {
        id: 'side-inject-' + Date.now(),
        role: 'user',
        content: [{ type: 'text', text: '【' + entry.title + ' 摘要】\n' + summary }],
        source: { kind: 'plugin', plugin: 'sidechat' },
      }
      mainAgent.inject(message)
      entry.updatedAt = Date.now()
      return { ok: true, summary }
    }

    async function closeChat(mainSessionId, sideId) {
      const entry = entryOf(mainSessionId, sideId)
      if (!entry) return { ok: false, error: '未知侧对话' }
      sideChats.delete(sideId)
      try {
        await entry.handle.dispose()
      } catch (err) {
        console.error('[side-chat] dispose 失败', err)
      }
      try {
        await workspaceRegistry.archiveSession(entry.sessionId)
      } catch (err) {
        console.error('[side-chat] 归档失败', err)
      }
      bumpVersion()
      return { ok: true }
    }

    // ---- 事件监听：状态同步 ----
    ctx.on('agent/status', ({ agent, status }) => {
      const entry = sideChats.get(agent.id)
      if (!entry) return
      entry.status = status
      entry.updatedAt = Date.now()
    })
    ctx.on('agent/error', ({ agent, error }) => {
      const entry = sideChats.get(agent.id)
      if (!entry) return
      entry.error = error && error.message ? String(error.message) : String(error)
      entry.updatedAt = Date.now()
    })

    // ---- RPC（Client 面板） ----
    harness.handle('sidechat/open', async (args) => {
      const mainSessionId = String((args && args.mainSessionId) || '')
      const firstMessage = args && typeof args.firstMessage === 'string' ? args.firstMessage : ''
      if (!mainSessionId) return { ok: false, error: '缺少主会话 ID' }
      try {
        return await openChat(mainSessionId, firstMessage)
      } catch (err) {
        console.error('[side-chat] open 失败', err)
        return { ok: false, error: (err && err.message) ? String(err.message) : String(err) }
      }
    })
    harness.handle('sidechat/send', async (args) => {
      const mainSessionId = String((args && args.mainSessionId) || '')
      const sideId = String((args && args.id) || '')
      const text = String((args && args.text) || '')
      if (!mainSessionId || !sideId) return { ok: false, error: '参数缺失' }
      try {
        return await sendMessage(mainSessionId, sideId, text)
      } catch (err) {
        return { ok: false, error: (err && err.message) ? String(err.message) : String(err) }
      }
    })
    harness.handle('sidechat/state', async (args) => {
      const mainSessionId = String((args && args.mainSessionId) || '')
      if (!mainSessionId) return { ok: false, error: '缺少主会话 ID' }
      return stateOf(mainSessionId)
    })
    harness.handle('sidechat/events', async (args) => {
      const mainSessionId = String((args && args.mainSessionId) || '')
      const sideId = String((args && args.id) || '')
      if (!mainSessionId || !sideId) return { ok: false, error: '参数缺失' }
      return eventsOf(mainSessionId, sideId)
    })
    harness.handle('sidechat/bring-back', async (args) => {
      const mainSessionId = String((args && args.mainSessionId) || '')
      const sideId = String((args && args.id) || '')
      if (!mainSessionId || !sideId) return { ok: false, error: '参数缺失' }
      try {
        return await bringBack(mainSessionId, sideId)
      } catch (err) {
        return { ok: false, error: (err && err.message) ? String(err.message) : String(err) }
      }
    })
    harness.handle('sidechat/close', async (args) => {
      const mainSessionId = String((args && args.mainSessionId) || '')
      const sideId = String((args && args.id) || '')
      if (!mainSessionId || !sideId) return { ok: false, error: '参数缺失' }
      try {
        return await closeChat(mainSessionId, sideId)
      } catch (err) {
        return { ok: false, error: (err && err.message) ? String(err.message) : String(err) }
      }
    })

    // ---- /side 命令 ----
    commands.register({
      name: 'side',
      description: '打开一条并行侧边对话（独立上下文，结果可摘要带回主对话）',
      input: { hint: '首条消息（可选）' },
      handler: async (invocation) => {
        const first = invocation.rawInput.trim()
        try {
          const res = await openChat(invocation.agent.id, first || undefined)
          if (!res.ok) return { kind: 'error', text: res.error }
          return { kind: 'success', text: '已创建' + res.title + '（' + res.id + '）' }
        } catch (err) {
          return { kind: 'error', text: (err && err.message) ? String(err.message) : String(err) }
        }
      },
    })

    // ---- 插件停止时清理所有侧对话 ----
    ctx.effect(() => {
      return () => {
        for (const entry of sideChats.values()) {
          try {
            entry.handle.dispose()
          } catch (err) {
            console.error('[side-chat] 清理失败', err)
          }
        }
        sideChats.clear()
      }
    })
  },
}
```

            : chats.map((c) => React.createElement('div', {
                key: c.id,
                className: 'dsh-sidechat-item' + (c.id === selectedId ? ' sel' : ''),

      },

# dsh-side-chat

DSH 侧边对话插件 —— **并行侧边对话**：在主对话之外开一条**真实并行 agent 会话**（独立上下文、共享工作区），结束后把结论**摘要带回主对话**，主对话上下文不被污染。

> 免构建、纯 JavaScript、MIT 许可。一份源码既是本仓库内容，也是 DSH 动态 Cordis 插件的 Host/Client 半体。

## 特性

- **真实并行 agent 会话**：每条侧对话是一个独立的 DSH Session + Agent，沿用主会话的 agent preset、模型路由与工作目录，但**不共享对话历史**。
- **上下文隔离**：侧对话的提问、工具调用不会进入主对话上下文。
- **自由切换**：侧边面板列出所有侧对话，点击即切换，互不串扰。
- **摘要带回主对话**：一键让侧 agent 总结自己的对话，摘要以用户消息注入主会话；主 agent 下一轮即可看到结论。
- **关闭即归档**：关闭侧对话 = 停止 agent + 归档会话，会话列表保持整洁。
- **`/side` 命令**：`/side 你的问题` 直接开一条侧对话（Web 面板会自动打开）。

## 设计要点

| 设计要点 | 本插件 |
| --- | --- |
| `/side` 斜杠命令 | `/side [消息]` 命令 + 面板「＋ 新建」 |
| 独立上下文窗口 | 独立 Session + Agent（同 preset、同工作区） |
| 线程自由切换 | 面板会话列表点击切换 |
| summarize & bring back | side agent 自总结 → 摘要注入主会话 |
| ephemeral / 丢弃 | 关闭即停止 agent、归档会话；注册表为内存态，重启不恢复 |

完整设计见 [`docs/design.md`](docs/design.md)。

## 安装

本插件通过 **DSH 动态 Cordis 插件**流程加载（免构建、免 npm 依赖）：

1. 在 DSH Web 会话中打开动态插件定义界面（cordis 插件工具）。
2. 新建插件：
   - **Host 半体**：粘贴 [`src/host.js`](src/host.js) 的完整内容。
   - **Client 半体**：粘贴 [`src/client.js`](src/client.js) 的完整内容。
   - idPrefix 建议 `side`，名称 `DSH Side Chat`。
3. 运行该插件，在浏览器中批准 Client 半体授权。
4. 刷新页面：侧边栏底部出现「⤳ 侧边对话」入口。

> 动态插件是进程内、临时性的：DSH 重启后需重新加载。将插件固化为 loader 行 / npm 包（正式安装）列入 v2 路线。

## 使用

- 点击侧边栏底部「⤳ 侧边对话」开/关面板；「＋ 新建」创建侧对话。
- 在面板输入框发消息（Enter 发送）；状态点：灰 = 空闲，亮 = 运行中，红 = 出错。
- 「带回主对话」：侧 agent 自动总结，摘要注入主会话（主对话空闲时可用）。
- 「关闭」：停止该侧 agent 并归档会话。
- 命令行：`/side 查一下 xxx` 直接创建并发送首条消息。
- 限制：每个主会话最多 **8** 条并发侧对话。

## 架构

**Host 半体**（`src/host.js`，DSH Node 进程）

| 职责 | 实现 |
| --- | --- |
| 侧对话注册表 | 内存 `Map`，每主会话上限 8 |
| 创建侧会话 | `agentLoop.createAgent`（同 preset / 同 cwd / parentSession 血缘） |
| 消息注入 | `agent.send(message, 'next-turn', true)` |
| 状态同步 | 监听 `agent/status`、`agent/error` |
| 摘要带回 | `agent.send(总结请求)` → `whenIdle()` → `sessions.flush` → `readSession` 取末条 assistant 文本 → `mainAgent.inject(摘要)`（不唤醒主 agent） |
| 关闭 | `handle.dispose()` + `workspaceRegistry.archiveSession` |
| 命令 | `commands.register` 注册 `/side` |
| RPC | `harness.handle`：`sidechat/open`、`send`、`state`、`events`、`bring-back`、`close` |

**Client 半体**（`src/client.js`，浏览器）

| 职责 | 实现 |
| --- | --- |
| 入口按钮 | `sidebar.footer.action`（id `sidechat-toggle`） |
| 侧边面板 | `shell.overlay`（id `sidechat-panel`，380px 右侧浮层） |
| 数据刷新 | 面板打开时 1s 轮询 `sidechat/state` + `sidechat/events` |
| 自动开面板 | 监听 `openSignal`（`/side` 命令触发） |
| 样式 | `styles.insert` + `--dsw-alias-*` 主题变量（明暗自适应） |

**数据流**

```
面板输入 → host.call('sidechat/send') → sideAgent.send(…, wake) → 侧 agent 处理 → 面板轮询显示回复
带回主对话 → host.call('sidechat/bring-back') → 侧 agent 自总结 → 摘要注入主会话 → 主 agent 下一轮可见
```

## 限制与 FAQ

- **重启不恢复**：侧对话注册表是内存态；DSH 重启后侧对话仍作为普通会话存在于会话列表，可手动打开查看。
- **`/side` 在 Web 输入框的可见性**：取决于当前 DSH 版本对自定义命令的暴露程度；面板按钮在所有版本可用。
- **主对话忙碌时**「带回主对话」会提示稍后重试（不会打断进行中的主对话）。
- **侧对话是真实会话**：可在会话列表/搜索中找到它们（标题为「侧对话 #N」）。
